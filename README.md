Библиотека IntegerValues
Простая библиотека .NET для работы с целыми числами, включающая модульные тесты, CI/CD и документацию.

Функционал
Округление: Кастомная логика округления double → int.

Проверка чётности: Быстрая битовая проверка.

Модуль числа: Обработка крайних случаев (например, int.MinValue).
